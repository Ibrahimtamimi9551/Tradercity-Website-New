# TraderCity Frontend Constitution V1

Version: 1.0

Status: Active

Owner: TraderCity

## Mission

TraderCity is not a broker, exchange, prop firm, or signal-selling
platform. TraderCity is an ecosystem connecting elite traders with
ambitious traders through education, analysis, community, and
collaboration.

## Technology Stack

-   Next.js 16
-   React 19
-   TypeScript 5
-   Tailwind CSS 4
-   Tabler Icons

## Non-Negotiable Rules

### Allowed

-   React Components
-   TypeScript
-   Tailwind CSS
-   Inline SVGs
-   Modular architecture
-   Responsive design
-   Reusable components

### Forbidden

-   Standalone HTML pages
-   index.html generation
-   Vanilla JavaScript pages
-   jQuery
-   Bootstrap
-   Global CSS dumps
-   Random UI libraries

## Architecture

``` text
src/

│   ├── home/
│   ├── ui/
│   └── layout/
├── data/

```
