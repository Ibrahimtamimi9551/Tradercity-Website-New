# TraderCity Homepage Refinement Agent

## Chapter 05 --- TraderCity Design System & Visual Language

**Version:** 1.0\
**Status:** Living Specification

> This chapter defines the visual language of TraderCity. It is the
> reference for every homepage refinement and should be treated as the
> single source of truth for UI consistency.

------------------------------------------------------------------------

# 1. Purpose

The design system exists to ensure every screen feels like it belongs to
one product.

The objective is not visual variety.

The objective is visual consistency.

Users should recognize TraderCity immediately regardless of which
section they are viewing.

------------------------------------------------------------------------

# 2. Design Philosophy

TraderCity should feel:

-   Institutional
-   Premium
-   Professional
-   Calm
-   Technical
-   Modern
-   Research-first
-   Long-term

Never feel:

-   Flashy
-   Loud
-   Over-animated
-   Casino-like
-   NFT-inspired
-   Meme-driven

------------------------------------------------------------------------

# 3. Brand Personality

TraderCity represents confidence through clarity.

Core traits:

-   Intelligent
-   Credible
-   Trustworthy
-   Analytical
-   Educational
-   Disciplined

Every interface should reinforce these traits.

------------------------------------------------------------------------

# 4. Color Language

Core Brand Colors

-   Deep Space Navy (#05081A)
-   Purple (#9B5DE5)
-   Indigo (#5E5CE6)
-   Cyan (#06D6F7)
-   Gold (#D4AF37)

Semantic Colors

Success - Emerald

Warning - Amber

Error - Rose

Information - Cyan / Blue

Use color with intention, not decoration.

------------------------------------------------------------------------

# 5. Typography System

Typography communicates hierarchy before color.

Recommended scale

Display XL - Hero headlines

Display LG - Section headlines

Heading - Cards and subsections

Body - Explanations

Caption - Supporting information

Label - Eyebrows and metadata

Typography should remain consistent across all sections.

------------------------------------------------------------------------

# 6. Spacing System

Whitespace creates premium perception.

Guidelines

-   Maintain consistent vertical rhythm.
-   Align section spacing.
-   Preserve readable line lengths.
-   Avoid cramped layouts.

Whitespace is a design element.

------------------------------------------------------------------------

# 7. Grid & Containers

Use a predictable layout system.

Objectives:

-   Stable reading width
-   Consistent gutters
-   Responsive scaling
-   Alignment between sections

Do not create unique layouts for every section without purpose.

------------------------------------------------------------------------

# 8. Glass Card Recipe

Shared characteristics:

-   Soft border
-   Subtle backdrop blur
-   Layered depth
-   Moderate radius
-   Calm shadows

Cards should feel unified across Hero, Analysts, Membership and Pricing.

------------------------------------------------------------------------

# 9. Button Language

Buttons should communicate confidence.

Primary - Main CTA

Secondary - Supporting action

Ghost - Low emphasis

Destructive - Rarely used on homepage

Keep button behavior consistent.

------------------------------------------------------------------------

# 10. Section Structure

Every section should contain:

Eyebrow

↓

Headline

↓

Description

↓

Primary Content

↓

Evidence

↓

CTA (when appropriate)

Avoid mixing unrelated content.

------------------------------------------------------------------------

# 11. Component Inventory

Reusable primitives include:

-   SectionContainer
-   SectionEyebrow
-   SectionHeading
-   SectionDescription
-   PremiumButton
-   GlassCard
-   GradientText
-   Divider
-   Badge
-   StatCard

Always reuse before creating.

------------------------------------------------------------------------

# 12. Borders & Elevation

Hierarchy should be created through:

-   spacing
-   contrast
-   borders
-   elevation

Avoid excessive shadow intensity.

Depth should remain subtle.

------------------------------------------------------------------------

# 13. Iconography

Icons support comprehension.

Guidelines:

-   Follow one project-wide icon system.
-   Keep sizing consistent.
-   Avoid decorative icon usage.
-   Use icons to reinforce meaning.

------------------------------------------------------------------------

# 14. Motion Language

Motion should communicate state changes.

Allowed

-   Fade
-   Slide
-   Scale (subtle)
-   Hover feedback

Avoid

-   Bounce
-   Spin
-   Large parallax
-   Excessive delays

Animation should never compete with content.

------------------------------------------------------------------------

# 15. Visual Hierarchy

The eye should naturally move:

Headline

↓

Description

↓

Visual

↓

Evidence

↓

Action

Never allow decorative elements to dominate.

------------------------------------------------------------------------

# 16. Imagery

Illustrations should:

-   explain
-   support
-   reinforce

Never exist purely for decoration.

Images should represent the TraderCity ecosystem rather than generic
crypto imagery.

------------------------------------------------------------------------

# 17. Premium UI Checklist

Before approving any UI change ask:

-   Does it improve clarity?
-   Does it improve consistency?
-   Does it improve trust?
-   Does it reduce cognitive load?
-   Does it strengthen the ecosystem narrative?

If not, reconsider the design.

------------------------------------------------------------------------

# 18. Do's

-   Prefer reusable patterns.
-   Keep interfaces calm.
-   Maintain generous whitespace.
-   Use typography to create hierarchy.
-   Keep interactions predictable.
-   Design for long sessions.

------------------------------------------------------------------------

# 19. Don'ts

-   Don't add effects without purpose.
-   Don't introduce inconsistent spacing.
-   Don't mix visual styles.
-   Don't create one-off components.
-   Don't sacrifice performance for aesthetics.
-   Don't imitate crypto marketing sites.

------------------------------------------------------------------------

After reading this chapter the agent should understand:

-   Which primitives to reuse.
-   How to evaluate visual quality.
-   How to preserve a premium institutional identity.
