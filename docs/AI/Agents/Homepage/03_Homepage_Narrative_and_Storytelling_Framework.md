# TraderCity Homepage Refinement Agent

## Chapter 03 --- Homepage Narrative & Storytelling Framework

**Version:** 1.0\
**Status:** Living Specification

> This chapter defines the narrative architecture of the TraderCity
> homepage. It explains **why every section exists**, what business
> problem it solves, what emotion it should create, and how it connects
> to the next section.

------------------------------------------------------------------------

# 1. Guiding Principle

The homepage is not a landing page made from independent blocks.

It is one continuous narrative.

Every section must answer a question raised by the previous section.

No section exists purely for decoration.

The visitor should never feel lost or ask, "Why am I seeing this now?"

------------------------------------------------------------------------

Visitor

# 3. Section Design Rules

Every homepage section must define:

-   Business Objective
-   User Question
-   Emotional Goal
-   Information Goal
-   Visual Priority
-   CTA
-   Transition to Next Section

Avoid sections that attempt to explain multiple unrelated concepts.

------------------------------------------------------------------------

# 4. Hero Section

## Purpose

Capture attention immediately and establish TraderCity's identity.

## User Question

"What is TraderCity?"

## Business Objective

Introduce TraderCity as an intelligence ecosystem rather than a trading
community.

## Emotional Goal

Curiosity. Confidence. Professionalism.

## Information Goal

Communicate:

-   Crypto is complex.
-   Multiple perspectives are required.
-   TraderCity connects them.

## Visual Direction

Large typography.

Institutional aesthetics.

Minimal distractions.

Premium depth.

## CTA

Guide users toward understanding before asking them to join.

## Never

-   Overload the hero.
-   Explain every feature.
-   Use marketing buzzwords.

------------------------------------------------------------------------

# 5. Ecosystem Overview

## Purpose

Demonstrate that crypto markets contain multiple connected disciplines.

## User Question

"Why can't one strategy solve everything?"

## Information Goal

Visualize interconnected market perspectives.

Examples:

-   Price Action
-   Orderflow
-   Liquidity
-   Macro
-   On-chain
-   Research

## Emotional Goal

Expand the visitor's understanding.

------------------------------------------------------------------------

# 6. Problem Awareness

## Purpose

Help visitors recognize the problem before presenting the solution.

## User Question

"Why do traders struggle?"

Core Message

Most traders do not fail from lack of effort.

They fail from lack of context.

Avoid blaming users.

Educate instead.

------------------------------------------------------------------------

# 7. Trader Solution

## Purpose

Introduce TraderCity's philosophy.

## User Question

"How is TraderCity different?"

Core Message

Different analysts answer different questions.

One ecosystem creates complete understanding.

Explain the framework rather than selling features.

------------------------------------------------------------------------

# 8. Analyst Team

## Purpose

Humanize the ecosystem.

## User Question

"Who produces this intelligence?"

Business Goal

Increase trust.

Communicate specialization.

Show diversity of expertise.

Never present analysts as influencers.

Present them as domain specialists.

------------------------------------------------------------------------

# 9. Community

## Purpose

Demonstrate collaborative learning.

## User Question

"Who will I learn with?"

Community Values

-   Respect
-   Curiosity
-   Discussion
-   Continuous learning
-   Long-term improvement

Avoid hype-focused messaging.

------------------------------------------------------------------------

# 10. Membership

## Purpose

Demonstrate ecosystem access.

Membership is not a purchase.

Membership is participation.

Highlight:

-   Full Research
-   Education
-   Analysts
-   Community
-   Frameworks

VIP should feel like a logical progression.

------------------------------------------------------------------------

# 11. Knowledge Vault

## Purpose

Show that TraderCity compounds knowledge over time.

Content Types

-   Learning Frameworks
-   Research Reports
-   Weekly Intelligence
-   Archives
-   Educational Systems

The knowledge vault should communicate permanence rather than content
velocity.

------------------------------------------------------------------------

# 12. Pricing

## Purpose

Convert trust into action.

Pricing should reinforce value.

Avoid aggressive sales language.

Present pricing as the gateway into the ecosystem.

------------------------------------------------------------------------

# 13. Storytelling Principles

Every section should:

-   Build on previous context.
-   Reduce uncertainty.
-   Increase trust.
-   Increase clarity.
-   Introduce only one primary concept.

Transitions between sections should feel natural.

------------------------------------------------------------------------

# 14. Visual Storytelling

Visual hierarchy should mirror information hierarchy.

Primary headline

↓

Supporting explanation

↓

Illustration

↓

Evidence

↓

CTA

Avoid visual competition between elements.

------------------------------------------------------------------------

# 15. Emotional Journey

The homepage should progressively move users through:

Curiosity

↓

Recognition

↓

Understanding

↓

Trust

↓

Belonging

↓

Commitment

Every refinement should preserve this emotional rhythm.

------------------------------------------------------------------------

# 16. Content Principles

Prefer:

-   Education
-   Clarity
-   Evidence
-   Frameworks
-   Context

Avoid:

-   Fear
-   Urgency
-   Hype
-   Price-first messaging
-   Empty marketing claims

------------------------------------------------------------------------

# 17. Homepage Success Metrics

After reading the homepage, a visitor should understand:

-   Why crypto markets are complex.
-   Why multiple perspectives matter.
-   Why TraderCity exists.
-   Why analysts are valuable.
-   Why research compounds over time.
-   Why membership unlocks a complete ecosystem.

------------------------------------------------------------------------

# 18. Agent Decision Framework

Before changing any section, ask:

1.  What question does this section answer?
2.  Does it support the overall story?
3.  Does it improve trust?
4.  Does it improve clarity?
5.  Does it connect to the next section?
6.  Does it preserve the TraderCity vision?

If the answer to any of these is "no", reconsider the implementation.
