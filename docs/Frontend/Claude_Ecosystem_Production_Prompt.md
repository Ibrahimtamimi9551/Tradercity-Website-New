# Project Lead Decision #3

# Claude Prompt --- Ecosystem Production Conversion

You are converting an already-approved visual design into production
code.

## PROJECT STACK

-   Next.js 16
-   React 19
-   TypeScript
-   Tailwind CSS 4

------------------------------------------------------------------------

## OBJECTIVE

Convert the existing ecosystem section into a production-ready React
component.

------------------------------------------------------------------------

## IMPORTANT

The design has already been approved.

Do NOT redesign.

Do NOT reinterpret.

Do NOT simplify.

Do NOT modernize.

Do NOT improve aesthetics.

Your goal is visual fidelity.

The final component should look as close as possible to the approved
reference.

------------------------------------------------------------------------

## PRIORITY ORDER

1.  Visual fidelity
2.  Responsive behavior
3.  Clean component structure
4.  Maintainability

------------------------------------------------------------------------

## REQUIREMENTS

-   Create `components/home/Ecosystem.tsx`
-   Use TypeScript
-   Use Tailwind CSS
-   Use inline SVG where required
-   No global CSS
-   No standalone HTML
-   No CSS files
-   No external UI libraries
-   No visual redesign

------------------------------------------------------------------------

## IMPLEMENTATION RULES

If a visual effect is difficult to recreate:

Attempt the closest possible implementation rather than replacing it
with a different design.

Do not remove visual elements simply because they are difficult to
implement.

Preserve:

-   Layout hierarchy
-   Visual relationships
-   Node structure
-   Connection structure
-   Spacing proportions
-   Visual balance
-   Ecosystem storytelling

------------------------------------------------------------------------

## OUTPUT FORMAT

Provide:

1.  File path
2.  Complete component code
3.  Required imports
4.  Any supporting helper files (if necessary)
5.  Integration instructions

------------------------------------------------------------------------

## SUCCESS CRITERIA

The final output should:

-   Match the approved visual reference as closely as possible
-   Be production-ready
-   Be directly usable in the existing TraderCity project
-   Follow TraderCity Frontend Constitution V1
-   Follow TraderCity Design System V1

The implementation should feel like a faithful conversion of the
approved design, not a redesign.
